What it does

A local fuel estimator for daily driving. No account, no ads, no cloud.

Remaining fuel and range

The gauge estimates liters left and how far you can go from odometer, consumption, and tank size.

More than one car

Switch vehicles, edit tank and consumption, and keep each car’s fuel history separate.

Fuel log

Every fill is saved with date, odometer, and liters added — full tank or partial.

GPS trips

Track kilometres in the background, then add them to the odometer when you stop — or discard the trip.

GasBuddy shortcut

Jump to nearby stations without leaving your fuel numbers behind. The app does not send your data to GasBuddy.

Stays on your device

Vehicle details and logs never leave the phone. Location is used only while a GPS trip is running.

How it works

Three numbers in, a live estimate out. Add fuel after you fill up so it stays honest.

Set up the car

Enter tank size, average consumption, and odometer. First run treats the tank as full at that reading.

Calculate

Update current kilometres. The gauge shows remaining fuel and estimated range for the active car.

Add fuel

Log liters added or a full tank. That locks the last fill odometer and keeps the estimate on track.

Install

Sideload the APK

Download the latest build from GitHub Releases and open it on your phone. Android may ask you to allow installs from that source.

Needs Android 7+. GPS trips need location access, and a notification permission on Android 13+. Fuel logging still works if you skip GPS.

The app id is com.digitalfuelgauge. An older FuelCheck install is not overwritten — it shows up as a second app.

Build it yourself

Clone the repo and run ./gradlew assembleDebug, or open the project in Android Studio. Release builds use ./gradlew assembleRelease.
